# Will You Be My Bestie?

An interactive web page asking the simple question: "Will you be my bestie? Like... forever and ever?"
## Features
- Animated GIF background display.
- Interactive "Yes" and "No" choice navigation.
- Live deployment hosted via GitHub Pages.
